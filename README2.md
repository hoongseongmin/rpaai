# 🤖 RPA/AI 자동화 플랫폼 (v1.0.0)

본 프로젝트는 반복적인 문서 작성(공문, 청구서)과 데이터 추출, 파일 비교 등의 업무를 웹 브라우저 상에서 원클릭으로 자동화하기 위해 개발된 사내 맞춤형 플랫폼입니다.

---

## 🌟 주요 기능

### 1. 🚀 원클릭 일괄 생성 (`/oneclick`)
- 고객사를 선택하고 이번 달의 **[공통 날짜]** 와 **[금액 정보]** 만 한 번 입력하면 관련된 모든 공문과 청구서를 즉시 생성합니다.
- 브라우저 캐시(Local Storage)를 활용하여 이전에 입력한 데이터를 기억하고 연동합니다.
- **PDF 서비스 수준 관리 보고서**를 업로드하면 파이썬이 데이터를 자동으로 읽어와 입력칸을 알아서 채워줍니다.

### 2. 📝 상세 편집 대시보드 (`/rpa`)
- 문서를 최종 생성하기 전, 엑셀/워드에 들어갈 모든 변수를 한눈에 확인하고 직접 수정할 수 있는 에디터 화면입니다.
- 수정된 금액에 맞춰 **실지급액, 청구금액, 부가세 등이 실시간으로 자동 연산**됩니다.

### 3. 📄 PDF 추출 확인 (데이터 랩) (`/pdf-test`)
- 파이썬과 OCR(광학 문자 인식) 기술이 PDF 파일에서 텍스트와 표를 어떻게 읽어 들이는지 눈으로 직접 확인할 수 있는 테스트 페이지입니다.

### 4. ⚙️ 파일 처리 도구 (`/`)
- 기존 운영현황과 신규 운영현황 CSV/Excel 파일을 비교하여 **[신규추가, 내용변경, 삭제됨]** 항목을 자동으로 분류하고 요약된 엑셀 파일로 추출합니다.
- 이미지 리사이즈, 포맷 변환 등의 유틸리티를 지원합니다.

## 🏢 고객사 맞춤형 자동화 파이프라인 (우정사업본부)

엑셀 설정 파일(`[설정]_우체국_공문1_2.xlsx`, `[설정]_우체국_공문3_4.xlsx`)과 연동하여 아래 5가지 프로세스를 완벽하게 자동화합니다. 다운로드 파일명은 자동으로 최신 청구연월을 반영하여 깔끔하게 생성됩니다.

1. **이전설치 공문 (Word)**
   - `공문_금융자동화기기(Ⅱ) 유지관리용역 이전설치 완료통보의 건({청구연월}분).docx`
2. **이행실적 공문 (Word)**
   - `공문_금융자동화기기(Ⅱ) 유지관리용역 {청구연월} 이행실적 검사요청.docx`
3. **이전실비 청구서 (Excel)**
   - `청구공문_금융자동화기기(Ⅱ) 유지관리용역 이전실비({청구연월}분).xlsx`
4. **유지보수료 청구서 (Excel)**
   - `청구공문_금융자동화기기(Ⅱ) 유지관리용역 유지보수료({청구연월}분).xlsx`
5. **제증명 서류 3종 발급 가이드**
   - 정부24 및 사회보험 징수포털 다이렉트 링크 제공

*(✅ 생성된 워드와 엑셀 파일은 버튼 한 번으로 **PDF로 즉시 변환**할 수 있습니다.)*

## 📂 디렉토리 구조 및 템플릿 관리

```text
rpaai/
├── data/
│   ├── templates/          # 통합 템플릿 보관
│   │   └── 우체국/         # 우정사업본부 전용 템플릿 및 설정 파일
│   ├── uploads/            # 사용자가 업로드한 임시 파일
│   └── outputs/            # 자동 생성된 최종 문서 및 PDF 저장소
├── src/
│   ├── automation/         # 문서 생성 및 비교 엔진
│   └── routes/             # API 엔드포인트 정의
├── templates/              # HTML 웹 브라우저 화면(UI) 디자인
└── main.py                 # 서버 실행 메인 파일
```

## 🌐 외부 동료와 플랫폼 공유하기 (ngrok 활용)

개발된 플랫폼을 같은 팀원들과 외부에서도 함께 사용하려면 `ngrok`을 활용하세요.

1. **서버 실행**: 터미널에서 파이썬 서버를 켭니다.
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```
2. **ngrok 실행**: 새로운 터미널 창(또는 ngrok.exe)을 열고 아래 명령어를 입력합니다.
   ```bash
   ngrok http 8000
   ```
3. **주소 공유**: 화면에 출력된 `Forwarding` 주소(예: `https://a1b2...ngrok-free.app`)를 복사하여 팀원들에게 메신저로 공유합니다. 
   *(이 링크를 통해 누구나 플랫폼에 접속해 문서를 자동 생성할 수 있습니다!)*

> **⚠️ 주의사항**: 엑셀의 PDF 변환 기능은 서버가 실행 중인 PC의 '백그라운드 MS 엑셀'을 제어하여 수행되므로, 서버 컴퓨터에 반드시 MS Office가 설치되어 있어야 합니다.

## 🔄 컴퓨터를 껐다 켤 때 (재시작 가이드)

초기 설정(ngrok 회원가입 및 토큰 등록)은 최초 1회만 하면 됩니다. 이후 컴퓨터를 껐다 켤 때는 아래 **2가지 명령어**만 다시 실행해 주세요.

1. **파이썬 서버 켜기**: 터미널에서 `uvicorn main:app --host 0.0.0.0 --port 8000` 실행
2. **ngrok 다시 켜기**: `ngrok.exe` 실행 후 `ngrok http 8000` 입력
   - 🚨 **중요**: ngrok 무료 버전은 프로그램을 껐다 켤 때마다 **새로운 접속 주소**가 발급됩니다. 새로 생성된 링크를 팀원들에게 다시 공유해 주셔야 합니다. (같은 사무실이라면 ngrok 대신 본인 컴퓨터의 내부 IP(예: `http://192.168.x.x:8000`)를 공유하는 것이 주소가 바뀌지 않아 편리합니다.)

## 🛠️ 코드 수정 시 반영 방법 (개발자용)

- **프론트엔드 (HTML/JS/CSS)**: 코드 수정 후 브라우저에서 **새로고침(F5)**만 하면 즉시 반영됩니다.
- **백엔드 (Python)**: 서버를 껐다 켜야 반영됩니다. 단, 서버를 실행할 때 **`--reload` 옵션**을 붙여서 실행(`uvicorn main:app --host 0.0.0.0 --port 8000 --reload`)하면 파이썬 코드를 저장할 때마다 서버가 자동으로 즉시 재시작되어 실시간으로 반영됩니다!
