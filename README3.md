# 🏢 RPA/AI 자동화 플랫폼 - 고객사별 모듈 가이드

이 문서는 `static/js/customers/` 폴더에 위치한 **고객사별 개별 자바스크립트 설정 파일**들의 역할과 구성, 각 고객사별 특징을 설명합니다.

---

## 🌟 고객사 모듈의 역할
플랫폼 내에서 "고객사"를 선택했을 때 화면이 어떻게 바뀔지, 어떤 산출물(Task)을 생성할지, 기준월은 언제로 할지를 정의하는 핵심 파일들입니다. HTML을 건드리지 않고 이 폴더에 JS 파일만 추가/수정하여 고객사를 쉽게 관리할 수 있습니다.

### 📝 주요 속성 설명
- `monthOffset`: 청구 기준월 설정 (`0`=당월, `-1`=전월).
- `tasks`: 해당 고객사가 처리해야 할 작업(산출물) 목록.
  - `op: 'doc_official'`: 실제 파이썬 백엔드를 통해 Word/Excel 문서를 생성하는 작업.
  - `op: 'check_only'`: 문서 생성 없이, 화면에서 체크박스와 **부가세 계산기**(공급가액/부가세/합계금액)를 띄우는 작업.
  - `op: 'check_simple'`: 문서 생성 및 계산기 없이, 오직 **단순 체크박스**만 띄워 상태를 관리하는 작업.
- `renderOneclick`: 원클릭 화면(`oneclick.html`)에서 해당 고객사를 선택했을 때 노출할 커스텀 UI(HTML)를 반환.
- `getDashboardKeys`: 대시보드 화면(`rpa_dashboard.html`)에서 수정 가능하게 띄울 변수 키 목록을 지정.

## 📂 고객사별 모듈 상세 안내

### 1. 우정사업본부 (`koreapost.js`)
- **기준월**: 전월 (`monthOffset: -1`)
- **특징**: 플랫폼 내에서 가장 복잡하고 고도화된 UI를 가짐. 
- **작업 목록**: 1~4번 엑셀 파일 개별/통합 생성, 5번 제증명 서류(정부24, 징수포털 링크) 가이드.
- **UI 구성**: 이전설치 공문 정보, 이행실적 통계 및 금액, 이전실비 청구서, 유지보수료 청구서 등 4개의 블록으로 나뉨. PDF에서 서비스 수준 통계를 추출하는 기능 포함.

### 2. 한네트 (`hannet.js`)
- **기준월**: 당월 (`monthOffset: 0`)
- **특징**: '글로리'와 '자동화기기' 두 개의 고객사 설정을 하나의 파일에서 관리.
- **작업 목록**: 청구공문 생성 (Word) 1종.
- **글로리 (`hannet_glory`)**: 입력칸 없이 100% 엑셀 파일 연동.
- **자동화기기 (`hannet_atm`)**: 화면에서 **기기 수량**을 입력받고, 엑셀의 '보수단가'와 연동하여 자동으로 **청구금액**을 산출하는 하이브리드 계산 로직 포함.

### 3. 하나은행 (`hanabank.js`)
- **기준월**: 당월 (`monthOffset: 0`)
- **특징**: 기본 템플릿 사용. 커스텀 UI 없이 안내 문구만 노출.
- **작업 목록**: 청구공문 생성 (Word) 1종.

### 4. 한화갤러리아 (`hanwhagalleria.js`)
- **기준월**: 당월 (`monthOffset: 0`)
- **특징**: 문서 생성 작업과 단순 체크리스트가 혼합된 형태.
- **작업 목록**: 1. 청구공문 생성(Word), 2. 정기점검서 요청(`check_simple`).

### 5. 한화손해보험 (`hanwhainsure.js`)
- **기준월**: 당월 (분기별)
- **특징**: 한화갤러리아와 이름이 헷갈리지 않게 `hanwhainsure`라는 고유 ID 사용.
- **작업 목록**: 1. 유지보수 청구서 공문 작성(Word), 2. 정기점검서 요청(`check_simple`).

### 6. 신한카드 (`shinhancard.js`)
- **기준월**: 분기별
- **특징**: 문서 생성 없이, 화면을 깔끔하게 유지하기 위한 **단순 체크박스 전용** 모듈.
- **작업 목록**: 장애지원내역 작성 및 계산서 발행 (`check_simple`).

### 7. SC은행 (`scbank.js`)
- **기준월**: 분기/반기별
- **특징**: 여러 개의 체크리스트를 한 번에 관리.
- **작업 목록**: 운영현황 작성, 정기점검서, 검수확인서, 취약점 점검 등 7종의 순수 체크리스트(`check_simple`) 구성.

### 8. 기타 나이스씨엠에스 / 신협 계열 (`nice_*.js`, `shinhyup.js`)
- *해당 파일들은 본 요약 문서의 스코프 외이지만, 각 계열사/지점별 엑셀 파일 구조와 계산기 표출(`check_only`) 등의 로직을 개별적으로 담당하고 있습니다.*

## 💡 새로운 고객사(모듈) 추가하는 방법

새로운 고객사를 추가할 때는 **기존 코드를 건드릴 필요 없이** 다음 3단계만 수행하면 됩니다.

1. **JS 파일 생성**: `static/js/customers/` 폴더에 `[고객사ID].js` 파일을 만듭니다. (예: `scbank.js` 참고)
2. **HTML 연결**: `oneclick.html`과 `rpa_dashboard.html` 하단의 `<script>` 태그 목록에 새 파일을 추가합니다.
    ```html
    <script src="/static/js/customers/[고객사ID].js"></script>
    ```
3. **매니저 등록**: `static/js/customer_manager.js`의 `customers` 배열에 고객사 ID와 이름을 추가합니다.
    ```javascript
    { value: "[고객사ID]", name: "화면에 보일 고객사명" }
    ```
